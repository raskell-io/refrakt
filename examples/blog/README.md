# Blog Example

A blog application built with [Refrakt](https://github.com/raskell-io/refrakt)
and PostgreSQL.

Apart from this README, every file here was generated by the Refrakt CLI;
nothing was edited by hand:

```bash
gleam run -m refrakt_cli -- new blog --db postgres
cd blog
gleam run -m refrakt_cli -- gen resource posts title:string body:text published:bool
gleam run -m refrakt_cli -- gen auth
gleam run -m refrakt_cli -- gen page about
gleam run -m refrakt_cli -- gen island counter
```

The only change is in `gleam.toml`: `refrakt` and `refrakt_cli` are path
dependencies on `../../packages/`, so the example always tracks the
library and CLI in this repository.

## Features

- Posts with title, body, and published flag (full CRUD)
- User registration, login and logout (Argon2id password hashes)
- About page
- A Lustre island (`web/islands/counter.gleam`), ready to embed in a view

## Setup

Needs PostgreSQL on `localhost:5432` that accepts the `postgres` user, or
a `DATABASE_URL` pointing elsewhere.

```bash
createdb -U postgres blog_dev

# Generate src/blog/migrate.gleam on first run and apply the migrations
gleam run -m refrakt_cli -- migrate

# Start the server
gleam run
# → http://localhost:4000/posts
```
