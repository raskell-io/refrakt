# Tasks App Example

A task management app built with [Refrakt](https://github.com/raskell-io/refrakt)
and SQLite.

Apart from this README, every file here was generated by the Refrakt CLI;
nothing was edited by hand:

```bash
gleam run -m refrakt_cli -- new tasks_app --db sqlite
cd tasks_app
gleam run -m refrakt_cli -- gen resource tasks title:string completed:bool
```

The only change is in `gleam.toml`: `refrakt` and `refrakt_cli` are path
dependencies on `../../packages/`, so the example always tracks the
library and CLI in this repository.

## Features

- Tasks with title and completed flag
- Full CRUD (create, read, update, delete)
- SQLite database (no external server needed)

## Setup

```bash
# Generate src/tasks_app/migrate.gleam on first run and create tasks_app.db
gleam run -m refrakt_cli -- migrate

# Start the server
gleam run
# → http://localhost:4000/tasks
```

## Routes

```bash
gleam run -m refrakt_cli -- routes
```

```
GET     /                       home_handler.index
GET     /tasks                  task_handler.index
GET     /tasks/new              task_handler.new
POST    /tasks                  task_handler.create
GET     /tasks/:id              task_handler.show
GET     /tasks/:id/edit         task_handler.edit
PUT     /tasks/:id              task_handler.update
DELETE  /tasks/:id              task_handler.delete
```
